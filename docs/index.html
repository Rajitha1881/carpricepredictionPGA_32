1. Used Car Market Valuation & Price Prediction

An end-to-end regression system to forecast market selling prices for used automobiles. Includes text unit parsing, vehicle depreciation engineering, formal inferential statistical tests (t-tests, ANOVA, Chi-Square), and non-linear ensemble modeling.

Feature Engineering

Cleaned complex unit notations (kmpl, CC, bhp, rpm), extracted manufacturer brands, and derived age depreciation metrics.

Statistical Validation

Validated price divergences across transmission types via two-sample t-tests and verified multi-category variances via One-Way ANOVA.

Key Drivers

Engine max power (~72% importance) and vehicle age (~20% importance) accounted for over 92% of predictive importance.

2. In-Vehicle Contextual Coupon Acceptance Prediction

Predicts whether a driver will accept an in-vehicle promotional coupon (restaurant, bar, coffee shop) based on immediate contextual attributes (weather, passenger, time, destination) and demographic characteristics.

Overfitting Diagnostics

Identified severe variance in unpruned decision trees (99.4% train vs 59.8% CV) and applied max-depth constraints to restore model stability.

ROC-AUC Optimization

Trained a 1000-estimator Gradient Boosting Classifier (GBM), validating discrimination capability with ROC curve diagnostics near 1.0 AUC.

Data Preprocessing

Handled high-missingness columns (>99% NaN), imputed category frequencies, and applied Label and One-Hot encoding across 25 features.

3. Financial Credit Default Risk Prediction & Multi-Model Benchmarking

Classifies customer loan and credit default risk using banking profile indicators (Employment status, Bank Balance, Annual Salary). Resolves real-world financial default class asymmetry and benchmarks 7 classification architectures.

Class Imbalance Resolution

Implemented targeted random undersampling to balance non-default instances with default events, preventing majority-class bias.

Automated 7-Model Suite

Engineered an automated evaluation pipeline benchmarking Logistic Regression, SVC, Decision Trees, AdaBoost, Gradient Boosting, Random Forest, and KNN.

Optimal Architecture

Random Forest Classifier achieved top accuracy at 88.06%, closely followed by AdaBoost (87.31%) and Gradient Boosting (86.57%).
